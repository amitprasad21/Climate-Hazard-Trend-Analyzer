# Dashboard design entry point

The authoritative visual specification is [frontend/docs/design.md](frontend/docs/design.md). It owns palette, typography, spacing, surfaces, focus, motion, charts and visual acceptance. Keep tokens there; this root file remains a navigation entry point for existing instructions and tools.
