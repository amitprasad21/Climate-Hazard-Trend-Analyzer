[Audit](system-design-audit.md) separates existing files from proposals; [task overview](../TASKS.md) links the authoritative trackers.

DOC-006/DOC-007 document the capability audit and [shared role workflow](ai-development-workflow.md); DOC-008 is conditional tool activation. These mappings add development checkpoints, not runtime completion. Existing layer authorities and all original concept IDs/names remain intact.

Status vocabulary: **Documented** = design/workflow reviewed, no runtime claim; **Planned** = implementation/verification pending; **Implemented** = specified code exists, remaining acceptance explicitly listed; **Verified** = complete stated acceptance with linked executed evidence; **Deferred** = intentionally excluded with trigger; **Blocked** = named decision/prerequisite prevents completion. These are concept statuses, distinct from task TODO/IN_PROGRESS/BLOCKED/DONE. No concept is marked Verified solely from prose or a raw endpoint probe. Every deferred item still has an owner and review/test activity.
